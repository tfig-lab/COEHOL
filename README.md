# Painel COE Holambra

### 👉 [Abrir o painel: tfig-lab.github.io/COEHOL](https://tfig-lab.github.io/COEHOL/)

Painel do desenho pré-implementação do Centro de Excelência Operacional (COE) da Cooperativa Agroindustrial Holambra.

- Modelo 3D da Unidade Avaré: https://tfig-lab.github.io/COEHOL/holambra-avare-3d/
- Arquitetura To-Be em 3D: https://tfig-lab.github.io/COEHOL/arq3d/

- `index.html` — painel completo (Início, Objetivos, Desafios, Indicadores, Infraestrutura e dados, Viabilidade, Governança, Roadmap)
- `holambra-avare-3d/` — modelo 3D da Unidade Avaré, com telas do COE por etapa e mapa de câmeras (inclui modo de edição das câmeras)
- `arq3d/` — arquitetura To-Be do COE em 3D
- `img/`, `dados/` — imagens usadas pelo painel

Observação: fora do Claude, o modo de edição das câmeras salva apenas no navegador de quem edita; use "Exportar CSV" para consolidar as posições.
